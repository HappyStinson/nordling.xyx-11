## 2024 Update

Well this project never really took off. I remember having build issues with the technology we were using. It was written in C++ and used a custom wrapper around Haaf's Game Engine (HGE).
To my surprise I see there's still a version of [HGE](https://kvakvs.github.io/hge/) being maintained so I might look into getting a version of Dansk Mask working again (given I find our source code after all this time)... Wish me Luck! {% emoji "🍀", "four leaf clover" %}
