## Change Log Flag Frenzy v0.4

- New update loop. Switch case statement with game state instead of if-else structure. To be able to handle Game Over in a nicer way
- Hold down space to hoist the flag. Now you do not have to smash it (but please continue smashing the like and subscribe buttons on [YouTube](https://youtube.com/@RasNordling))
- A clock that counts down before the game starts. Ready, Set, GO!
- The timer is a separate entity that talks to GameController and runs like a coroutine
- Added the text "Time left" in front of the time which is now printed in full seconds

## 2025 Update

I built this game with Unity in 2014 and it used to run in web browsers with the Unity Web Player. With the advent of HTML5, browsers began to remove support for plug-ins, and Unity’s web player was deprecated in 2015. {% emoji "😵", "face with crossed-out eyes" %}
It's no longer possible to play the game unfortunately. As of now I don't have any plans of re-making the game with modern technologies.
