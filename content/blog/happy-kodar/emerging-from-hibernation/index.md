I've looked into cross-compiling with CMake and written a first toolchain file, which basically means compiling code for a platform other than the one performing the compilation. {% emoji "😅", "grinning face with sweat" %} That means it'll be ~~damn~~ really easy (I hope) to build, for example, an exe-file (executable Windows program) on my Linux machine!
